## 基本结构

```tsn
# 这是注释，整行忽略

:: block_name
@say "..."
@jump other_block

:: other_block
@say "..."
```

- `::` 定义块。块名不能重复。脚本的**第一个块**是入口。
- `@` 开头是指令。**每行最多一条**。
- `#` 开头是注释，行尾也可以写注释。
- 块之间通过 `@jump` 跳转。

## 对话

```tsn-fragment
@say "这是一句旁白。"
@say 小雪 "这是一句台词。"
```

- `@say "..."` → 旁白，无角色名。
- `@say 角色名 "..."` → 有角色名的对话。

**角色名不加引号。** 名字里有空格用引号包：`@say "老张 张" "..."`。

**台词里的引号用中文的 `""`，不用转义。**

### 台词里插入变量

用 `{变量名}` 把变量的值放进台词：

```tsn-fragment
@set name = "阿德里安"
@say "你好，{name}。"
```

- 数字、字符串、`true` / `false` 都能插
- **没设过的变量原样显示**（`{who}` 就显示成 `{who}`），这样漏设一眼就能看出来，不会静默变成空白
- 只在**台词**里生效，`@if` 条件里不能这么写
- 打字机按展开之后的长度算，所以插值不会让打字机乱掉

## 场景与立绘

```tsn-fragment
@scene forest
@show adrian at 0.55 0.10 0.40 0.85
@hide adrian
@clear
```

- `@scene 名字` — 换背景。
- `@show 名字 at x y w h` — 显示立绘。
- `@hide 名字` — 隐藏指定立绘。
- `@clear` — 清空所有立绘。

**坐标全部是归一化的 0~1：**

| 参数 | 含义 |
|---|---|
| `x` | 左边缘距屏幕左边的比例 |
| `y` | 上边缘距屏幕顶部的比例 |
| `w` | 宽度占屏幕的比例 |
| `h` | 高度占屏幕的比例 |

**常见位置：**

| 位置 | x | y | w | h |
|---|---|---|---|---|
| 居中 | 0.30 | 0.10 | 0.40 | 0.85 |
| 右侧 | 0.55 | 0.10 | 0.40 | 0.85 |
| 左侧 | 0.05 | 0.10 | 0.40 | 0.85 |

**但这几个 `w` / `h` 不能照抄**——它们决定立绘会不会被压扁。
`x y w h` 都是屏幕比例，所以**立绘画出来的长宽比是 `(w × 屏宽) : (h × 屏高)`**，
只有它和原图一致时才不变形。

上面那行 `w=0.40 h=0.85` 在 16:9 屏幕上算出来是 `0.40×16 : 0.85×9` ≈ **0.84 : 1**。
所以：

| 原图比例 | 什么立绘 | 该用的 `w : h` |
|---|---|---|
| 0.84 : 1 | 半身 | `0.40 : 0.85`（就是上表的值） |
| 0.5 : 1（1:2 竖长条） | 全身 | `0.30 : 0.96` |
| 2 : 1（横幅） | CG 式 | `0.80 : 0.32` |

**换算**：想让立绘占屏幕高度的 `h`，那
`w = h × 0.5625 × (原图宽 ÷ 原图高)`（`0.5625 = 9/16`，16:9 屏幕的因子）。

**后 `@show` 的画在上面。** 有遮挡关系时注意顺序。同一个名字重复 `@show` 是**移动**它，不会叠出两个。

### 移动立绘

```tsn-fragment
@move alice to 0.30 0.10 0.40 0.85 over 0.6 ease_out
@move alice to 0.30 0.10 0.40 0.85 over 0.6
```

- 前四个数字是目标位置的归一化坐标（x y w h），和 `@show` 一样。
- `over` 后面是时长（秒）。
- 缓动曲线可选：`linear`（默认）/ `ease_in` / `ease_out` / `ease_in_out`。
- **阻塞**：移动期间点击不会推进剧情，和 `@wait` 一致。
- 移动期间**存档**会存目标位置（终态），读档后立绘直接在终点，不重播动画。
- 立绘不在舞台上时 `@move` 会报警告并跳过，不阻塞。

## 流程控制

```tsn-fragment
@jump chapter2

@if greeted
    @say "你打过招呼。"
@else
    @say "你没打招呼。"
@say "继续。"
```

- `@jump 块名` — 无条件跳转。
- `@if 条件` — 条件分支。`@else` 可选。

**缩进随意，只要同一块内一致。** 2 空格、4 空格、Tab 都能跑。

**`@if` 之后的内容如果没有 `@else`，直接接下一个同级指令：**

```tsn-fragment
@if flag
    @say "真"
@say "总是执行"
```

## 条件表达式

| 写法 | 含义 |
|---|---|
| `flag` | flag 为 true |
| `not flag` | flag 不为 true |
| `a and b` | 两个都为真 |
| `a or b` | 至少一个为真 |
| `score > 50` | 大于 |
| `score < 50` | 小于 |
| `score >= 50` | 大于等于 |
| `score <= 50` | 小于等于 |
| `score == 50` | 等于 |
| `score != 50` | 不等于 |

**优先级从低到高：`or` → `and` → `not` → 比较。** 括号可以改写：

```tsn-fragment
@if greeted and score > 50
@if not greeted or score < 10
@if score >= 10 and score <= 99
@if (a or b) and c
```

### 比较的语义（容易踩的地方）

- **`>` `<` `>=` `<=` 按数值比。** 整数变量和浮点字面量混着比也对，
  所以 `@if 好感 >= 5` 在好感是 `5.0` 时**成立**。变量没设过、或不是数字时算 false，不报错。
- **`==` / `!=` 比的是值本身。** 整数 `1` 和浮点 `1.0` **不相等**。要判断相等请用整数，
  或者写成范围。
- **浮点不要用 `==` 比。** 浮点是二进制近似，`0.1 + 0.2 != 0.3`。用 `>=` / `<=`。

## 选项

```tsn-fragment
@choice
    打招呼 -> greet { greeted = true }
    沉默 -> silent
    直接离开 -> leave { greeted = false, mood = "cold" }
```

- `显示文本 -> 目标块` — 基本形式。
- `{ 变量 = 值, ... }` — 可选，选中时设置这些变量。**值只能是字面量**（数字、字符串、
  `true` / `false`），不能写算式——要算数请在目标块里用 `@set`：

```tsn
:: start
@set 加班次数 = 0
@choice
    加班 -> work { 累了 = true }

:: work
@set 加班次数 = 加班次数 + 1
@say "又加了一天班。"
```

**`@choice` 至少需要一个选项。**

游戏里选项可以用鼠标点，也可以按数字键 `1`~`4`。**选项文本里的 `{变量}` 会在显示时展开。**

## 变量与算术

```tsn-fragment
@set score = 42
@set name = "阿德里安"
@set greeted = true
@set ratio = 0.75
```

- 整数：`@set score = 42`
- 浮点：`@set ratio = 0.75`（写 `3.0` 会当成整数 `3`）
- 字符串：`@set name = "阿德里安"`
- 布尔：`@set greeted = true` / `false`

**变量是全局的。** 在任意块里设，其他块都能读。

### 算术

右边可以写算式，也能引用别的变量：

```tsn-fragment
@set 好感 = 0
@set 好感 = 好感 + 1        # 自增
@set 好感 = 好感 * 2
@set 好感 = (好感 + 1) * 3  # 括号
@set 折扣 = 1 - 0.25
```

支持的运算符：`+` `-` `*` `/` `%`，一元负号 `-x`，括号。
**整数和浮点：** 两边都是整数就出整数（`8 / 2` = `4`），沾了浮点就出浮点（`7 / 2` = `3.5`）。

**显示：** 写进台词时会挑最短的表示——`3.0` 显示成 `3`，`1 / 3 * 3` 显示成 `1`
（不会出现 `1.0000000000000002` 这种）。超过 6 位小数才截断，所以做百分比、进度这类展示不用担心难看。

**算不出来时会怎样：** 除以 0、类型不对（字符串做减法）、或者变量还没值——
这些**不会让游戏崩，也不会停住剧本**，只是跳过这次赋值，并在控制台和屏幕上提示一句。
变量保持原样，总比悄悄变成错的值好。`--check` 会提前把"变量还没值"这类查出来。

## 演出

```tsn-fragment
@wait 0.5
@fade to 0.0 1.0
@fade to 1.0 0.5
@fade to 0.5 0.0
```

- `@wait 秒数` — 等待。期间点击无效。
- `@fade to alpha 时长` — 全局淡入淡出。

**`@fade` 的 alpha：** `0.0` 全黑，`1.0` 正常。

**常用转场组合：**

```tsn-fragment
@fade to 0.0 0.5      # 淡出到黑
@scene new_place      # 换背景
@clear                # 清立绘
@fade to 1.0 0.5      # 淡入
```

**`@fade to 0.0 0.0`** — 立刻切到全黑，不耗时。

## 音频

```tsn-fragment
@play bgm main
@play bgm battle
@play se click
@stop bgm
```

- `@play bgm 名字` — 播放 BGM（循环）。会先停掉当前 BGM。
- `@play se 名字` — 播放一次性音效。
- `@stop bgm` — 停止 BGM。

**简写：** `@bgm 名字` 等于 `@play bgm 名字`，`@se 名字` 等于 `@play se 名字`。两种写法都能用。

**`bgm` 和 `se` 是通道名。** 音频文件放在 `assets/audio/bgm/` 和 `assets/audio/se/` 下，
文件名（去扩展名）就是音频名。

**音量**在游戏里调（`Esc` 或 `O`），会写回 `config.toml` 的 `[audio]` 段。

**读档会恢复 BGM**：存档记住当前在播的那首，读档时自动接着播。

## 章节标记

```tsn-fragment
@chapter "第二章 · 湖边"
```

只给存档一个可读标签（存读档界面上显示"哪一章 + 当时那句台词"），**不改变画面**。
一般放在一章开头。同一段剧本里后面的 `@chapter` 会覆盖前面的。

## 结束与回标题

```tsn-fragment
@quit
@title
```

- **`@quit`** — 结束游戏（关窗口）。放在结局之后用
- **`@title`** — 回到标题画面。会把剧本**重新读一遍**、变量和回看历史全部清空，
  BGM 也停掉（标题画面自己会 `@play bgm`）

两条都是**终结性**的：走到就执行，不会继续往下跑。所以它们后面写什么都不影响。

简写也认：`@exit` = `@quit`，`@return_to_title` = `@title`。

`@title` 会重新读文件，所以**改完剧本按一下回标题就能看到新开头**，不用重启。

## 多文件

主文件用 `@include` 引入其他文件：

```tsn-fragment
# script.tsn
@include chapters/ch1.tsn
@include chapters/ch2.tsn

:: start
@jump ch1
```

被 include 的文件只写 `::` 块，不写 `@include` 和入口块。

**路径相对于当前文件。** `chapters/ch1.tsn` 里如果再 include，写 `sub/scene.tsn`
会找 `chapters/sub/scene.tsn`。

**修改任意被 include 的文件都会触发热重载。**

**报错会指到真正写错的那个文件。** 即使有十几层 include，报的也是
`chapters/ch2.tsn:9` 这样的位置，而不是"拼起来之后那一大段文本的第几行"。

## 完整示例

一个能重玩的短篇骨架：标题 → 分支 → 结局 → 回标题。

```tsn
# script.tsn
:: title
@chapter "标题"
@scene bg_title
@play bgm main
@say "——《电话》——"
@choice
    开始 -> start
    退出 -> quit

:: start
@scene bg_sunset
@set 打电话了 = false
@say "我被裁员了。我没有地方去了。"
@say "或许能试试打电话？"
@say "但是打给谁呢？"
@choice
    前女友 -> ex { 打电话了 = true }
    青梅 -> childhood { 打电话了 = true }

:: ex
@say "那个，我没地方去了……"
@wait 1.5
@say 前女友 "你怎么现在才知道找我？"
@jump ending

:: childhood
@say 青梅 "你这样了才知道找我，记得买几包薯片来。"
@jump ending

:: ending
@chapter "结局"
@fade to 0.0 0.8
@scene bg_night
@clear
@fade to 1.0 0.8
@if 打电话了
    @say "有人愿意接你的电话。"
@else
    @say "电话那头，很安静。"
@say "—— 完 ——"
@title

:: quit
@say "下次再打吧。"
@fade to 0.0 1.5
@quit
```

## 常见错误

| 错误 | 原因 |
|---|---|
| `@say 小雪 你好` | 字符串没加引号 |
| `@if greeted and` | 条件不完整 |
| `@choice` 后没缩进 | 选项需要缩进 |
| `@jump` 到不存在的块 | 块名拼错了 |
| `@set x = x + 1` 但 x 没赋过值 | 自增前要先 `@set x = 0`（`--check` 会提示） |
| 用了全角的 `＠` `：` `（）` | 必须用半角英文符号 |
| `@include` 路径写错 | 相对于当前文件 |

语法或跳转有问题时，**屏幕会画一页红字**告诉你哪个文件第几行错了，改好自动继续。
命令行校验用 `cargo run -- --check`（精确到行，不需要显卡）。

## 语法规则速查

| 想写 | 写法 |
|---|---|
| 旁白 | `@say "文本"` |
| 角色说话 | `@say 名字 "文本"` |
| 台词里插变量 | `@say "你好，{name}。"` |
| 换背景 | `@scene 名字` |
| 显示立绘 | `@show 名字 at x y w h` |
| 隐藏立绘 | `@hide 名字` |
| 清空立绘 | `@clear` |
| 跳转 | `@jump 块名` |
| 设变量 | `@set 名字 = 值` |
| 算术 | `@set 名字 = 别的变量 + 1`（`+ - * / %`、括号、一元负号） |
| 条件 | `@if 条件` / `@else` |
| 选项 | `@choice` + 缩进 |
| 停顿 | `@wait 秒数` |
| 淡入淡出 | `@fade to alpha 时长` |
| 章节标记 | `@chapter "第二章"` |
| 结束游戏 | `@quit` |
| 回到标题 | `@title` |
| 音乐 | `@bgm 名字`（= `@play bgm 名字`） |
| 音效 | `@se 名字`（= `@play se 名字`） |
| 停止音乐 | `@stop bgm` |
| 注释 | `# 内容` |
| 引入文件 | `@include 路径` |
