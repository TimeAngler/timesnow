# 美术方向 · 极简线条

这份文档是**做背景时要遵守的规矩**，不是审美偏好。
它针对的是一种刻意的风格：**纯色渐变 + 线条 + 少量实心形 + 一点光**，
没有纹理、没有透视细节、没有手绘笔触。

**为什么这份文档存在：** 风格的定义是"**一再重复的选择**"。
每张图单独决定颜色和线宽，做出来就是"素材还没做完"；按同一套规矩做，
才是"这是一种风格"。**两者差别只在一致性，不在精致度——而一致性不需要画技。**

## 一、三层结构：不同的东西有不同的存在方式

这个风格里只有三种画法，**各自对应一种存在**：

| 层 | 怎么画 | 对应什么 | `magick` 里的参数 |
|---|---|---|---|
| **结构** | 只描边的线 | 不呼吸的东西：铁栏、长凳、路面、塔 | `-Lines` |
| **身体** | 填充的实心形 | 会动、会呼吸的东西：人 | `-Keys` |
| **光** | 模糊的多边形/圆 | 不可触摸的东西：太阳、月亮、照进来的光 | `-Light` |

**别混用。** 人不要用线画，结构不要用填充画。**这个区分本身就是风格的一半。**

## 二、线宽是情绪参数，不是技术参数

这是这个风格里最有力、也最容易被忽略的一条。**同样的几何形状，只改
`stroke-width`，读出来的意思完全不同。**（`corinna` 的教堂实测过）

| 线宽 | 读出来 |
|---|---|
| **2–3** | 冷、空、远，甚至有点脆弱——像纸上的草图 |
| **5** | 克制。**关得住人，但它不喊叫**（现在的牢房） |
| **7–9** | 沉重、有压迫感、像权力 |

**所以"想要更强的情绪 → 先调线宽，别加形状。"**
加形状要重新想构图；调线宽是一个数字。

**在同一个故事里用线宽做对比**，能表达"处境变了"：

| 场景 | 线宽 | 为什么 |
|---|---|---|
| 教堂（圣女受拥戴） | **7–9** | 既是庇护，也是权力 |
| 牢房 | 5 | 关得住，但不喊叫 |
| 审判庭 | **2–3** | 冷的、空的、没有庇护 |

## 三、光等于意义

**有光/无光，是"这件事有没有意义"。** 同一张牢房，加一道光之后意思全变：
夜里（暗光）、有东西从外面进来（中光）、光成了主角（强光）。

**规矩：**

- **光只用在剧本里提到过的东西上。** 现在只有两个：教堂的太阳
  （民众说「雨就是她让上帝降下的」）、牢房夜的月光
  （`@say "月光正安静地待在铁栏内"`）。
- **宁弱勿强。** 光一强，它就不再是"照进来的光"，而变成"一块白色的东西"——
  **结构被压过去，画面就没有"里面"和"外面"了。**
- 想加光的时候先问：**这道光在剧本里对应什么？** 说不上来就别加。

### 实例：`cell_night` 的这一道光

这一张改了三版才成立，过程值得记下来：

| 版本 | 问题 |
|---|---|
| 只有月亮（没有光） | 月亮"挂在墙上"，**没有光进来**——夜里和白天只是换了颜色 |
| 月亮 + 光 | **光斑打在月亮上**（月亮自己发光还要被光穿过，读起来怪）；月亮还被画面右边裁掉 |
| **窗户 + 光（定稿）** | 窗是**结构**（用线画框），窗内的亮色是**主体**，光从窗里射到地面 |

**关键决定：把那道光的来源画出来。** 只有光斑、没有光源，
读者不知道光从哪来；画出窗户之后，**"月光从窗户进来"一眼就成立**。

**做光的时候先决定"光从哪来"，再画光。**

**一个取舍要知道**：原来满屏的竖线读起来像"你我之间隔着铁栏"（更压抑），
加了窗户之后铁栏变成"窗户上有栏杆"（更写实）。
两种都对，但情绪不同——**这是构图选择，不是技术问题。**

## 四、调色板（从现有背景里量出来的，别另起一套）

全部颜色都压在**暗区**，因为文字要压在画面上面。

### 冷组 —— "审判"（被关起来、被审）

```
#0c0e18   #111424   #15192d      ← 最暗，牢房夜
#181821   #191922   #20202b      ← 牢房
#1b1b23   #23232c   #282831      ← 审判庭
#2e2e38   #3a3a4a                ← 线（比底色亮一档，才看得见）
```

### 暖组 —— "外面的世界"（有人、有光）

```
#17150f   #1e1a15   #26221b      ← 庭外、街道
#312d25   #39342b   #493f33      ← 建筑、路面
```

### 教堂（唯一明亮的场景）

```
#6b7488                          ← 建筑主体
#94abc3   #d4cdb5                ← 天空
#e4d6b1   #eddaaf                ← 太阳、暖光
```

**教堂是全篇唯一明亮的场景**，其余全在 `#16`–`#29` 这个窄暗区。
**这个对比是有意的**：开场是唯一的"暖"和"亮"，之后一路变冷变暗。

**一张图只用 2–4 个颜色**（加渐变的两端）。**这是"看起来是一套"的最大来源。**

## 五、构图：下面 22% 不存在

文本框占屏幕下方 **158 / 720 ≈ 22%**（`config.toml` 里 `y = 0.72, h = 0.22`）。

- **要让人看见的东西 → 放在 y < 500**（留余量）
- **底部只放"地面感"**：暗色块、渐变收深、路面

**踩过的坑**：`court_outside` 的人群原本画在 y=450–530，**被文本框整个盖住**。
提到 y=340–415 才有用。

## 六、一张图只讲一件事

一张图有**一个"视觉支点"**，其余都是陪衬：

| 背景 | 支点 |
|---|---|
| `cathedral` | 太阳（从教堂背后升起） |
| `cell` | 铁栏 |
| `cell_night` | 窗户 + 那道月光 |
| `court` | 长凳 |
| `court_outside` | 一排人群剪影 |
| `street` | 两侧建筑 + 路面透视 |

**加任何东西之前问：它在剧本里对应什么？说不上来就别加。**
极简里每一根线都在聚光灯下——**"随便加两笔让它不那么空"是最糟的做法，比留白糟得多。**

## 七、同景不同光：只改颜色和光，不改形状

`cell` → `cell_night` 就是这么做出来的：**形状一模一样，只换了颜色和月亮。**

**这是最省的一致性**，也是这个风格最值钱的地方——**一处场景可以有两个情绪版本，
成本是零。**

## 八、怎么做

```powershell
# 一张新背景
powershell -ExecutionPolicy Bypass -File tools/make-bg.ps1 `
    -Name forest -Top '#1e2318' -Bottom '#12160e' -LineWidth 5 `
    -Lines 'line 0,430 1280,470' `
    -Keys 'fill #2a3222 stroke none ellipse 300,300 60 90 0 360' `
    -Project examples/corinna

# 同景不同光：只改颜色，加个月亮
powershell -ExecutionPolicy Bypass -File tools/make-bg.ps1 `
    -Name forest_night -Top '#141a20' -Bottom '#0a0e14' -LineWidth 5 `
    -Lines 'line 0,430 1280,470' `
    -Keys 'fill #d8dce8 stroke none circle 1000,140 1000,60' `
    -Project examples/corinna

# 加一道光
powershell -ExecutionPolicy Bypass -File tools/make-bg.ps1 `
    -Name forest_dawn -Top '#242a30' -Bottom '#14181c' -LineWidth 5 `
    -Lines 'line 0,430 1280,470' `
    -Light '400,0 700,0 900,500 600,500' -LightColor '#666c80' -LightBlur 30 `
    -Project examples/corinna
```

**`-draw` 里能用的形状**（MVG 语法，按顺序叠加）：

| 写法 | 作用 |
|---|---|
| `fill #rrggbb stroke none` | 之后画的填充、不描边 |
| `stroke #rrggbb stroke-width N fill none` | 之后画的只描边 |
| `rectangle x1,y1 x2,y2` | 矩形 |
| `polygon x1,y1 x2,y2 x3,y3 ...` | 多边形（三角、梯形、透视都用它） |
| `circle cx,cy px,py` | 圆（第二点是**圆周上**一点） |
| `ellipse cx,cy rx ry 0 360` | 椭圆——**必须写 `0 360`**，只给两个数会报错 |
| `line x1,y1 x2,y2` | 线 |

**光晕的做法**：先画实心圆再高斯模糊（`-blur 0x48`），
再叠一个清晰的小圆当日面。见 `cathedral` 的做法。

## 九、体积（这些数字是量出来的）

| 输出方式 | 大小 | 说明 |
|---|---|---|
| 24 位 PNG | 647,664 B | 基准 |
| PNG8 + 128 色，**抖动** | 43,914 B | 渐变里全是可见噪点 |
| **PNG8 + 128 色，不抖动** | **15,164 B** | **默认**，渐变平滑 |
| PNG8 + Floyd-Steinberg | 126,354 B | 更糟 |

**脚本默认 `+dither`——关抖动既更小又更干净。**
因为暗色渐变很缓，128 色够用、不会出色带。**真看到色带就调 `-Chroma` 到 256。**

**JPEG 更小（约 32 KB）但会把硬线条糊掉**，所以是 `-Jpeg` 手动开，不做默认。

## 十、这份文档的用法

**做完一张新图，对着这十条过一遍。** 最容易违反的是：

1. 混了抽象层级（线画人、填充画结构）
2. 线宽和场景情绪不匹配
3. 光太强，压过结构
4. 关键信息放到了 y > 500
5. 一面图讲了不止一件事

**这五条都不是审美问题，是不一致问题——而不一致正是"看起来像半成品"的唯一原因。**
